# EvidenceFeed v3
- 30 sec and 3 min: Instagram-style multi-card visual feed.
- 10 min: deep structured reading.
- EN/PT toggle for every mode.
- General PubMed search removed.
- Add by DOI, exact title, PMID or article URL.
- Separate screenshot/photo input.
- Crossref is used for static exact-article identification when possible.

Important: GitHub Pages cannot safely store an AI API key. Real AI generation and screenshot recognition need a secure backend. This v3 does not expose a secret key in the browser.
